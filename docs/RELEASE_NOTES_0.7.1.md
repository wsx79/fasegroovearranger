Arranger now uses the Fase Groove family's installer and integrated update flow.

- **Windows: FaseGrooveArranger-Windows-Setup.exe**, with the English/Italian wizard, Start menu shortcuts, optional desktop shortcut and uninstall.
- **OPTIONS → SETTINGS → CHECK NOW** downloads the matching update. **INSTALL NOW** runs the setup silently or replaces a writable portable copy and reopens the app. LATER and SKIP THIS VERSION remain available.
- SHA-256 verification before installation and rollback if portable replacement fails. Projects, samples, exports, autosaves and preferences are preserved.
- Stable update ZIPs for Windows, universal macOS and Linux alongside the versioned portable archives. Updated IT/EN Markdown guides and privacy information.

**Upgrading from 0.7.0 or earlier:** install this release once manually. The old DOWNLOAD button opens GitHub; this version provides INSTALL NOW. Save your project before updating.

Native Windows/macOS/Linux checks include update integrity/staging/rollback, Windows install/silent upgrade/uninstall, and UI, MIDI, host and audio regressions. Windows setup is unsigned; macOS uses the family's ad-hoc/optional Developer ID signing workflow.
