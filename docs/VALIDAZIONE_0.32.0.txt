NOTE DI VERIFICA
- Il test di click vuoto sulla velocity fissa esplicitamente lo zoom: il punto
  di prova deve distare piu' di 12 pixel dai trigger, anche dopo Fit Song.
- La comparazione audio degli split esclude solo +/-3 ms dal bordo, dove
  interviene deliberatamente il nuovo declick; il resto conserva la verifica.
- Nessun assert ADSR, StateVariableTPTFilter o range AudioBuffer nelle prove
  DSP mirate. Le prove GUI Debug mostrano ancora assert JUCE
  relativi a finestre/componenti, TemporaryFile e stringhe; non sono stati
  dichiarati risolti dal lavoro sul DSP.
- FGA_SKIP_EXPORT_UI_TEST=1 esclude il lungo flusso interattivo di export;
  esportazioni native WAV/MP3, bounce VST e guard PCM sono verificati altrove.
- Non verificati hardware audio/MIDI, AU/macOS, Windows reale o plugin
  commerciali. Il test packaging Windows non equivale a una build Windows.
- Freeze e' una cache di sessione; analisi pitch/BPM e note spettrali sono
  stime. Il guard PCM non garantisce i picchi dopo codifica lossy.
